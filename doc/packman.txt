==============================================================================
INTRODUCTION                                            *packman-intro*

vim9-packman is a minimal, fast Vim9script package manager with parallel
git operations. It uses Vim's built-in |job_start()| API for async
updates, and provides |:PackmanInit| for synchronous init that blocks
vimrc until plugins are installed and loaded.

==============================================================================
CONFIGURATION                                          *packman-config*
 
Add the bootstrap snippet to the top of your |.vimrc|:

>
# vim9-packman auto initialization
const P = expand('~/.vim/pack/plugins/opt/vim9-packman')
if !isdirectory(P) && executable('git')
  mkdir(P, 'p')
  system('git clone --depth 1 ' .. shellescape('https://github.com/greeschenko/vim9-packman.git') .. ' ' .. shellescape(P))
endif

execute 'packadd vim9-packman'
<

Then configure your plugins after the bootstrap:
>
# Plugin list (supports "user/repo" format)
g:packman_plugins = [
  'greeschenko/vim9-packman',
  'user/repo',
  ...
]

# Sync init: install missing + load plugins (blocks vimrc)
packman#PackmanInit()
<

**Note:** All other options (g:packman_plugin_dir, g:packman_lockfile, etc.) are
optional and have sensible defaults.

==============================================================================
COMMANDS                                              *packman-commands*

|:PackmanInit|    Sync init: install missing + load plugins (blocks vimrc)
|:PackmanInstall|  Install all/missing/specified plugins (parallel)
|:PackmanInstallSync|  Deprecated: use |:PackmanInit| instead
|:PackmanUpdate|   Update all/specified plugins (parallel, shows per-plugin result)
|:PackmanClean|    Remove plugins not in g:packman_plugins
|:PackmanStatus|   Show plugin state (installed/outdated/missing)
|:PackmanLock|     Generate/update lockfile with current commit hashes

==============================================================================
LOCKFILE                                              *packman-lockfile*

The lockfile is a Vim-script file that pins plugins to exact commits for
reproducible installs. It is updated automatically on |:PackmanUpdate| or
manually with |:PackmanLock|.

Example lockfile:
>
vim9script
g:packman_lock = {
  'user/repo': 'a1b2c3d4e5f6',
}
<
